For Advanced Calculator Operations

This calculator supports various advanced mathematical operations, and here’s a guide to using them.

How to Use

1) Enter a Number:
   Start by entering a number on the screen. You can input any number using the number buttons.

2) Select the Operator:
   Once you have entered a number, select one of the advanced operators from the available list.
   These operators include:
    Square (x²): Computes the square of the entered number.
    Square Root (√): Computes the square root of the entered number.
    Logarithm (log): Computes the base 10 logarithm (log₁₀) of the entered number.
    Reciprocal (1/x): Computes the reciprocal of the entered number (i.e., 1 divided by the number).
    Sin (sin): Computes the sine of the entered angle in degrees.

3) Perform the Calculation:
   After selecting an operator, click the “=” button to perform the calculation.
   The result will first be displayed in the console and then on the screen.

* Advanced Operation Options:
  Advanced operations are hidden by default. To toggle the visibility of advanced operations, click the “🔀” button.
  This will reveal additional buttons for square, square root, logarithm, reciprocal, and sine.
